<h2>🚀 快速开始</h2>
<h3>1. 克隆项目</h3>
<pre><code class="hljs language-bash">git <span class="hljs-built_in">clone</span> https://github.com/fbwe425/blog-cms.git
<span class="hljs-built_in">cd</span> blog-cms
</code></pre>
<h3>2. 部署到 Cloudflare Pages</h3>
<ol>
<li>登录 <a href="https://dash.cloudflare.com">Cloudflare Dashboard</a></li>
<li>进入 <strong>Workers &#x26; Pages</strong> → <strong>Create</strong> → <strong>Pages</strong> → <strong>Connect to Git</strong></li>
<li>选择 GitHub → 授权 → 选择 <strong>blog-cms</strong> 仓库</li>
<li>配置构建：</li>
</ol>
<table>
<thead>
<tr>
<th>设置项</th>
<th>值</th>
</tr>
</thead>
<tbody>
<tr>
<td>Branch</td>
<td><code>main</code></td>
</tr>
<tr>
<td>Build command</td>
<td><code>hugo --minify</code></td>
</tr>
<tr>
<td>Build output directory</td>
<td><code>public</code></td>
</tr>
</tbody>
</table>
<ol start="5">
<li>
<p>在 <strong>Settings</strong> → <strong>Functions</strong> 中添加 KV 绑定：</p>
<ul>
<li><code>SESSIONS</code> → 选择或创建 KV 命名空间</li>
<li><code>AUTH_CREDENTIALS</code> → 选择或创建 KV 命名空间</li>
</ul>
</li>
<li>
<p>点击 <strong>Save and Deploy</strong></p>
</li>
</ol>
<h3>3. 设置管理员帐号</h3>
<p>在 Cloudflare Dashboard 中：</p>
<ol>
<li>进入 <strong>Workers &#x26; Pages</strong> → <strong>你的项目</strong> → <strong>Settings</strong> → <strong>Functions</strong> → <strong>KV namespace bindings</strong></li>
<li>点击 <strong>Edit variables</strong>，获取 KV 命名空间 ID</li>
<li>使用 Wrangler CLI 或 API 设置管理员帐号：</li>
</ol>
<pre><code class="hljs language-bash"><span class="hljs-comment"># 安装 Wrangler</span>
npm install -g wrangler

<span class="hljs-comment"># 登录</span>
wrangler login

<span class="hljs-comment"># 设置管理员帐号</span>
wrangler kv:key put --binding=AUTH_CREDENTIALS <span class="hljs-string">"admin"</span> <span class="hljs-string">'{"username":"admin","password":"你的密码"}'</span>
</code></pre>
<h3>4. 访问后台</h3>
<ol>
<li>打开 <code>https://你的站点.pages.dev/admin/</code></li>
<li>输入管理员帐号和密码</li>
<li>登录成功后即可使用后台管理</li>
</ol>

<h2>❓ 常见问题</h2>
<h3>Q: 后台登录失败怎么办？</h3>
<ol>
<li>检查 Cloudflare Pages Functions 是否正常运行</li>
<li>检查 KV 绑定是否正确配置</li>
<li>检查管理员帐号密码是否正确</li>
</ol>
<h3>Q: 如何修改密码？</h3>
<pre><code class="hljs language-bash">wrangler kv:key put --binding=AUTH_CREDENTIALS <span class="hljs-string">"admin"</span> <span class="hljs-string">'{"username":"帐号","password":"新密码"}'</span>
</code></pre>
<h3>Q: 图片存储在哪里？</h3>
<p>默认存储在 <code>static/images/uploads/</code> 目录，通过 Decap CMS 上传。</p>
<h3>Q: 如何添加新的分类？</h3>
<p>在后台 <strong>📝 文章管理</strong> 中，点击分类下拉框的 <strong>Add</strong> 按钮。</p>
<h3>Q: 本地开发时怎么用后台？</h3>
<p>本地开发时 Functions 无法使用。你可以临时修改 <code>config.yml</code> 使用 GitHub OAuth。</p>
